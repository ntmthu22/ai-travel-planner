# Sample data (placeholder)

These files exist so that `npm run dev` and `npm run agent` run on a fresh clone. They are **invented**:
the names say "Sample", the coordinates are not real places, and the version is
`sample-placeholder-NOT-the-shared-set`. They are **not** the shared dataset of the class. Do not use them
for a graded run or for the cost of one plan: copy the published `dataset.json` here (or set `DATA_DIR`)
and the formats may need `normalizePlace` in `src/data.ts` to be matched.

`s90` (no hours) and `s91` (no menu) are incomplete on purpose: they must never reach the agent.
